# Apta2Switch-Studio — Beta 1

Design toehold switches, extend their triggers, and compare candidates and 2D structures. Runs locally, in English or French.

Extract the archive and open the **Apta2Switch-Studio** folder. Double-click **Apta2Switch-Studio.app** (Mac) or **Apta2Switch-Studio** (Linux). The app opens in your browser.

The folder also contains **nupack**, **runs**, and **START-HERE.txt**. Keep them together: move the whole folder to a writable location such as Documents.

**No Python installation or terminal commands needed.** On Mac, you may need to allow the first launch in **System Settings → Privacy & Security → Open Anyway**.
